# 3D Scroll Animation

An interactive 3D web experience that combines scroll-based animations with real-time 3D rendering.

## Features

- Scroll-driven animation experience
- Interactive 3D scene
- Smooth animations and transitions
- Real-time 3D rendering
- Web-based interactive experience

## Technologies

- JavaScript (ES6+)
- Three.js
- GSAP
- lil-gui
- Vite
- HTML5
- CSS3

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/paknejad-farimah/scroll-animation-3D.git
   ```

2. Navigate to the project directory:

   ```bash
   cd scroll-animation-3D
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL provided by Vite in your browser.

## Build

To create a production build, run:

```bash
npm run build
```
